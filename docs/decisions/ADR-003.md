# ADR-003: クラスタリングは LLM に直接分類させる

- **Status**: accepted
- **Date**: 2026-09-22
- **Decider**: human (finalized at the mandate)
- **Related requirements**: R-3

## Background / problem

R-3 の受入基準に「キャッシュを迂回した2回実行の割当一致率を記録する」がある。この指標は
**LLM の非決定性を測る**ことを意図しているので、方式によって意味が変わる。

## Options

### Option A: LLM に直接分類させる
- Overview: 問題群を渡してグループ分けを返させ、排他分割と「その他」は後処理で強制する。
- Cost: 高い。200問の本文を入力トークンに載せ、分割呼び出しが複数回要る。
- Non-functional: 非決定的なので、割当一致率を測る意味が出る。
- Implementation effort: 小。実装が薄い。

### Option B: 埋め込み + 自前 k-means
- Overview: 埋め込み API を叩き、numpy 不在なのでピュア Python の k-means を書く。
- Cost: 埋め込みは LLM より1〜2桁安い。
- Non-functional: **埋め込みは概ね決定的なので、割当一致率が構造的に 100% 近くなり、受入基準1本の
  意味が変わる**。
- Implementation effort: 中。

### Option C: 併用(埋め込みで粗く → LLM が境界修正)
- Pros / cons: 退化しにくく安いが、2段になる分だけ退化ガードが赤くなったときの原因究明が難しい。

## Decision

**Adopted**: Option A(LLM に直接分類させる)

**Reason**: 受入基準が測ろうとしている非決定性が実際に現れる方式であること、および実装が最も薄いこと。

## Consequences / results

- 200問の本文が LLM の入力に載るので、**NFR-7 のコストがこのステージに集中する**。
- 排他分割と「その他」は LLM の出力を信用せず、後処理で強制する(型で保証)。
- 退化ガード(`1 < M`、最大クラスタ 50% 以下、その他 20% 以下)は合成フィクスチャに対する下層の
  判定。**上層(LLM が妥当なグループを返すか)は `artifact` の実測でしか分からない**。
- **What this requires of a person**: 実データの M/N と最大クラスタ比率を読んで圧縮の質を判定すること。
- **Reversibility**: 方式変更は可逆だが、**退化ガードの期待値が再検証になる**。
