## Notes / design decisions

- T-047 の2本の列(4f6872ef、ed330309)が、クラスタ要約の含意判定 `contradicted` で止まった(D-163)。
- 2026-09-28 に、リポジトリの外のスクリプトで切り分けた。
  - 32 クラスタ中、Haiku(元のプロンプト)は consistent 31、contradicted 1 だった。
  - その1件を、修正プロンプトの Haiku と、元のプロンプトの Opus は、どちらも consistent と判定した。
  - 人は「両方」を選んだ(ADR-019)。
- モデル ID とプロンプトは各段の `inputs_digest` に入る。そのため、cluster・recall・glossary・script の各段のキャッシュが1回無効になる(意図どおり)。
- 判定がモデルの能力として良くなったかは、このタスクでは測れない(D-044)。実データで確かめられるのは T-047 の列だけ。
- `tests/adapters/test_llm_claude_cli.py` の argv 比較は、`runner.specs[0]`(generate_recall、haiku)と `specs[1]`(summarize、opus)で行っている。含意判定のモデルやプロンプトを変えても、比較そのものは変わらない。
