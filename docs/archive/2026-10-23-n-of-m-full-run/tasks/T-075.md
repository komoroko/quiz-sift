## To do
- `pipeline/stage.StageCache` に、実行の列(`run_id` がある)のときだけ、キャッシュ鍵(`inputs_digest`)ごとの途中結果の場所 `out/<deck>/<stage>/<inputs_digest>.progress/` を足す。項目1件を1ファイルにし、ファイル名は項目の通し番号にする(本文を名前に使わない)。一時パスに書いてから `os.replace` で確定する。段の成果物を確定したら、その鍵の場所を消す。
- `recall/generate.generate_recall_set` は、問題ごとに、出力のあった生成の回数と状態を途中結果に書く(生成1回ごと、判定値が返った主張ごと)。状態は「通過」(想起素材・検査結果・作り直しの回数)、「失格」(上限超過。検査名と回数)、「途中」(使った回数、判定中の生成物、判定が済んだ主張の判定値)。
- 始めに途中結果を読む。通過した問題は呼び出さずに使い、クラスタをまたぐ重複の検査では前の問題として数える。途中の問題は、判定値のある主張を判定し直さずに残りの主張だけを判定し、使った回数の続きから数える(AR-25)。失格の問題があれば、作り直さずに、1回で走った場合と同じく全問を回したうえで `RegenerationExhausted` で止める(ADR-028、AR-14)。
- 呼び出しが失敗した生成(出力が無いもの)は回数に数えない。
- 再開のログは、途中結果から使った件数と残りの件数だけにする(NFR-2)。
- `cli.Pipeline.recall` を結線する。

## Acceptance criteria
> 機械が読む写しは `.rein/plan.yaml` のこのタスクの `acceptance:`。

- **A-1**: 途中結果は鍵ごとに分かれ、成果物の確定で消える。判定: command — `pytest -q tests/pipeline/test_stage.py::test_progress_is_keyed_by_the_stage_digest_and_removed_on_commit`
- **A-2**: 止まった後の再実行は残りの問題だけを呼び、重複の検査は戻した問題を数える。判定: command — `pytest -q tests/recall/test_generate.py::test_resume_skips_questions_that_passed`
- **A-3**: 作り直しの上限は再開をまたいで数える。(a) 上限超過の後に枠切れで止まると、再開しても作り直さずに `RegenerationExhausted`。(b) 3回目の生成の呼び出しが枠切れで失敗した問題は、再開で3回目として生成し、出力のあった生成は2回の実行を通して 3 回以下。(c) 判定の途中で uncertain の後に枠切れになった生成は、再開で聞き直さずに不合格として数える。判定: command — `pytest -q tests/recall/test_generate.py::test_regeneration_cap_holds_across_resumes`
- **A-4**: 実行の列で `--fresh-run` が枠切れで止まった後、`--resume` で recall が exit 0 になり、呼び出しの和が問題数と作り直しの回数の和を超えない。判定: command — `pytest -q tests/test_cli_sequence.py::test_recall_resume_continues_from_the_stopped_question`
- **A-5**: 再開のログは件数だけ。判定: command — `pytest -q tests/acceptance/test_analysis.py::test_recall_resume_logs_counts_only`

- **Test kind**: ユニットと受入(スタブの LLM が k 問目の後にレート枠の停止を返す)
- **Test file(s)**: tests/pipeline/test_stage.py、tests/recall/test_generate.py、tests/test_cli_sequence.py、tests/acceptance/test_analysis.py

## Notes / design decisions
- 成果物を書く条件は変えない(NFR-1)。途中結果は下流の段から読まない。
- 鍵に `run_id`・モデル・プロンプト・前段成果物が入るので、鍵が変われば途中結果は使われない。鍵が変わって使われなくなった途中結果は、前の列の成果物と同じく `out/` に残る(ADR-028)。
- 途中結果は教材由来の本文を含む。ログと例外文には出さない。
