> 判定すると、片方のテストを書かないだけで両方が緑になる。

- **A-1**: 回答の受け口が submit(session_id, question_id, chosen: OptionId) のみで、表示位置インデックスを受け取る API が存在しない。  
  判定: `pytest -q tests/scoring/test_api_shape.py::test_no_positional_index_api_exists`
- **A-2**: フィクスチャが問題ごとに異なる並びを持ち、少なくとも1問は正解 ID が表示位置 0 に来ない。その提示下で、選択肢 ID で同定した全問正解入力が正答率 100%、全問誤答入力が 0% になる。  
  判定: `pytest -q tests/scoring/test_grade.py::test_grading_under_nonidentity_shuffle`
- **A-3**: シャッフル seed が (セッション ID × 問題 ID) から導出され、同一問題の2セッションで presentation が異なる。  
  判定: `pytest -q tests/scoring/test_session.py::test_same_question_differs_across_sessions`
- **A-4**: レポートが既習フラグの値ごと(studied / unseen / unknown)に正答率を分けて出す。  
  判定: `pytest -q tests/scoring/test_report.py::test_report_splits_by_studied_flag`
- **A-5**: レポートに hold-out 不在とテスト効果の両方を明示した限界開示文が必ず含まれる。  
  判定: `pytest -q tests/scoring/test_report.py::test_limits_disclosure_is_always_present`
- **A-6**: 2セッション分の合成ログに対し、事前・事後それぞれの正答率と差分がレポートに出る。  
  判定: `pytest -q tests/scoring/test_report.py::test_pre_post_rates_and_delta`
- **A-7**: 問題ごとの選択・正誤・所要時間がストア越しに永続記録され、プロセスをまたいで読み戻せる。  
  判定: `pytest -q tests/scoring/test_persistence.py::test_attempts_survive_a_restart`
