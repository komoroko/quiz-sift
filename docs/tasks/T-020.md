  判定: `pytest -q tests/measurements/test_full_run_logs.py::test_reproducibility_records_doubled_calls`
- **A-3**: 生成した mp3 に対する無音構造判定の実行結果が docs/test/measurements/audio-silence.md に記録され、**全クラスタについて判定結果が真である**(3.0 秒以上の無音が前後を有音に挟まれて検出された)。1件でも偽なら赤。  
  判定: `pytest -q tests/measurements/test_full_run_logs.py::test_audio_silence_is_true_for_every_cluster`
- **A-4**: 実データの M/N・最大クラスタ比率・「その他」比率が full-run.md に数値として記録され、人が圧縮の質を判定できる。**3値のいずれかが欠ければ赤**(値そのものに合格ラインは設けない — D-004)。  
  判定: `pytest -q tests/measurements/test_full_run_logs.py::test_compression_metrics_are_present`
