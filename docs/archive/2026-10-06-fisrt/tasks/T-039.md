## To do

- `adapters/claude_process.py`: `SubprocessRunner`(env は4変数だけ、タイムアウト、stdin、タイムアウト時の途中の stdout)、`Workspace(home_root, cwd_root)`(`new_cwd` / 後始末 / `preflight`)、モジュール関数 `default_preflight`。

## Acceptance criteria

> 機械可読な写しは `.rein/plan.yaml` のこのタスクの `acceptance:` にあり、ループが読むのはそちら。

- **A-1**: 親環境に、NFR-8 が列挙した 13 個の metered 認証変数すべてに値を入れておく。その状態で SubprocessRunner が子プロセスへ渡す環境の変数名の集合は {HOME, PATH, LANG, TZ} と一致し(部分集合ではない)、HOME は最小ホームを指す。期待集合は、要件から写した定数としてテスト側に置き、実装の定数を読まない。PATH の値は親の PATH をそのまま写す。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_child_env_is_exactly_the_allowlist`
- **A-2**: Workspace(home_root, cwd_root) を tmp_path を根にした実物のまま走らせると、new_cwd() がリポジトリの外に空ディレクトリを作り、呼び出しの後始末でそれを消す。HOME 配下のファイル一覧は、new_cwd と後始末の前後で変わらない。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_workspace_makes_an_empty_cwd_outside_the_repo_and_cleans_it`
- **A-3**: preflight() は、最小ホームのディレクトリ自身の fd に対する fcntl.flock でロックを取り、ロックファイルを作らない。別プロセスが保持している間は、待たずにエラー終了する(D-105)。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_second_holder_fails_fast_without_a_lock_file`
- **A-4**: Workspace.preflight() の中身検査(ADR-017、D-122)。positive control: T-029 の実測形(.claude.json、.claude/settings.json = {"theme":"dark"}、skills/synced/…、plugins/synced/…、projects/…/*.jsonl、.claude/.credentials.json)は通る。空の .claude/rules/ と、settings.json が {} の場合も通る。次のそれぞれは、原因の相対パスと規則番号(i〜iv)をメッセージに持つ SystemExit の派生で終了する: .claude/CLAUDE.md(ファイル・symlink・ディレクトリの各形)、rules/a.md、rules/sub/b.md、settings.json に env・apiKeyHelper・hooks・permissions・enabledPlugins のいずれかがある、壊れた JSON、UTF-8 でないバイト列、トップレベルが []、資格情報ファイルが無い。許可キー集合 {theme} と拒否するパスは、要件からテスト側にリテラルで書き写す。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_preflight_rejects_by_content_and_accepts_the_measured_shape`
- **A-5**: preflight() は読むだけである。通った場合も落ちた場合も、ホーム配下のファイルの集合と各ファイルの内容・mtime が前後で変わらない。資格情報ファイルを chmod 000 にしても検査は通る(開いていれば PermissionError で落ちる。NFR-3 の control)。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_preflight_is_read_only_and_never_opens_credentials`
- **A-6**: 子の PATH に claude が無いとき、preflight() は非 0 のエラー終了になり、メッセージが claude の不在を名指す。この検査はロックより先に行う: 別プロセスがロックを持っていても、claude が無ければ claude の不在で落ちる。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_missing_claude_binary_fails_before_the_lock`
- **A-7**: SubprocessRunner は子プロセス1本ごとにタイムアウトを持つ(既定 10 分)。超過すると子を終わらせて TIMEOUT を返し、その結果は途中までの stdout を保持する(overage の走査に使う)。プロンプトは stdin でだけ渡り、一時ファイルを作らない。子の実行中に SystemExit の派生(signal.alarm のハンドラが送出する形)が起きたら、子を kill してから同じ例外を再送出する。結果の値(TIMEOUT や SPAWN)には変えない(AR-149)。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_timeout_keeps_partial_stdout_and_prompt_travels_only_on_stdin`
- **A-8**: claude_process を import しても、SubprocessRunner() と Workspace() を構築しても、ファイルシステムには何も起きない(D-115)。default_preflight はモジュール関数で、呼ばれたときに Workspace を構築して preflight() を走らせる。HOME を tmp の最小ホームに向けたとき、実測形では通り、資格情報が無ければ落ちる。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_construction_and_import_have_no_side_effects`
