## Notes / design decisions
- argv を変えると契約フィクスチャと overhead の定数が古くなり、記録を読むテストが赤になる。同じタスクで取り直して DoD を緑に保つ(AR-T4、AR-T9)。
- tests/adapters/test_claude_failure.py の FIXTURE_RATE_LIMIT は、契約フィクスチャ(success.stdout)の rate_limit_event を書き写した定数で、フィクスチャを取り直すと赤になる。値を差し替えず、テストがフィクスチャから期待値を読むように直す(build 中の escalation を受けた /revise で scope に追加)。
- D-193、D-213。home-probe の positive control は、ユーザ設定の遮断の下では作り直しが要るかもしれない。
- 最小ホームの settings.json は {"theme": "dark"} に戻ることを確かめる(NFR-3)。
- D-182。合成プロンプトだけなので可逆(D-108)。
