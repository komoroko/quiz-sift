## Acceptance criteria

> 機械可読な写しは `.rein/plan.yaml` のこのタスクの `acceptance:` にあり、ループが読むのはそちら。
> **受入基準1本につきテストのノード ID を1つ割り当ててある**(タスクレビュー AR-1)。

- **A-1**: Pause セグメントが 3.3 秒の無音 PCM として挿入され、mp3 エンコード後も 3.0 秒以上残る。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_inserted_pause_survives_mp3_encoding`
- **A-2**: detect_structure が区間列を返し、判定は「3.0 秒以上の Silent Run があり、その前後いずれにも Voiced Run がある」。末尾に無音を足すだけの実装が赤くなり、先頭/末尾に短い無音を含む音声は緑になる。  
  判定: `pytest -q tests/audio/test_silence.py::test_trailing_padding_goes_red_and_leading_silence_stays_green`
- **A-3**: ゼロ埋め連番のファイル名リストを sorted() した結果が意図順と一致し、m3u が出力される。  
  判定: `pytest -q tests/audio/test_naming.py::test_sorted_filenames_match_intended_order`
- **A-4**: AudioMeta の language と VOICE_TABLE[voice_id].language が一致する。  
  判定: `pytest -q tests/audio/test_voice_table.py::test_recorded_language_matches_voice`
- **A-5**: SynthesisReport が失敗クラスタを列挙し、部分成功時にプロセスが非0終了する。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_partial_failure_exits_nonzero`
- **A-6**: クラスタごと・合計の再生時間が記録される。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_durations_are_recorded`
- **A-7**: 日本語本文に英語のサービス名が混在するテキストを分割せずそのまま TTS ポートへ渡し、例外を投げない。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_mixed_language_text_is_passed_through`
- **A-8**: naming と playlist が 出力ディレクトリ・連番 prefix・識別子 を引数に取り、`audio/` を編集せずに別系列(グロッサリ・復習)を出力できる。cluster_id をハードコードする実装は赤になる。  
  判定: `pytest -q tests/audio/test_naming.py::test_naming_and_playlist_are_parameterised`

## Automated-test approach (the basis for the green decision)

- **Test kind**: unit / integration
- **Test file(s)**: `tests/audio/test_naming.py`, `tests/audio/test_silence.py`, `tests/audio/test_synthesize.py`, `tests/audio/test_voice_table.py`
- **Test target / cases** — 各ノードについて **何を壊すと赤になるか**:

  - **A-1**: 3.0 秒ちょうど挿入する実装 → mp3 後に 2.992 秒となり赤
  - **A-2**: 「ファイル内に無音がある」だけを見る実装 → 末尾パディングのフィクスチャで赤。先頭/末尾の短い無音で落ちる実装も赤
  - **A-3**: ゼロ埋めしない連番 → 10 が 2 の前に来て赤
  - **A-4**: 言語をメタデータから書きつつ常に日本語ボイスを使う実装 → 赤
  - **A-5**: 部分成功で 0 終了する実装 → 赤
  - **A-6**: 再生時間を記録しない実装 → 赤
  - **A-7**: 混在テキストを言語で分割しようとして例外を投げる実装 → 赤
  - **A-8**: naming が cluster_id をハードコードし、別 prefix で呼べない実装 → 赤

> ノード ID は「その名前のテストが存在すること」までしか強制しない — **空の本体(`pass`)でも exit 0 になる**
> ことは実測で確かめてある。上の行は、実装者とレビュアーがその空白を見つけるための唯一の非循環な手掛かりで、
> 最終的な防御はタスク DoD の `review` ステップ(コードレビュアーがテストを読む)。

## Notes / design decisions

- 実測(2026-09-22)で 3.000 秒の無音は mp3 で 2.992 秒になった。挿入 3.3 秒・判定 3.0 秒はその実測値。**生成した mp3 に無音があることは T-020 の実測**(ADR-012)。再レビュー AR-4 で A-8(命名の引数化)を追加。
