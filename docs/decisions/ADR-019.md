# ADR-019: 含意判定は Opus に、プロンプトは「省略・一般化は矛盾ではない」を明示する(ADR-015 を一部 supersede)

- **Status**: accepted
- **Date**: 2026-09-28
- **Decider**: human (finalized at the mandate)
- **Related requirements**: NFR-1、R-3

## Background / problem

T-047 のフル処理で、クラスタ要約の含意判定が `contradicted` を返し、列全体が止まった(D-042)。
判定まで届いた2本の列(4f6872ef、ed330309)の両方で起きた。

判定は `claude-haiku-4-5`(ADR-015)に任せている。プロンプトは次の2文だけだった。

> reference を正しい情報として、statement がそれと矛盾するかを判定する。矛盾しなければ consistent、矛盾すれば contradicted、reference から判断できなければ uncertain。

クラスタ要約は、複数の問題を省略・一般化したものである。プロンプトはこの形を想定していない。

2026-09-28 に、リポジトリの外に置いたスクリプトで切り分けた。分類から全クラスタの要約・判定までを、止めずに1列走らせた。
- 32 クラスタ中、Haiku(元のプロンプト)の判定は consistent 31、contradicted 1 だった。
- その1件を、次の2通りで判定し直した。
  - Haiku に「省略・一般化は矛盾ではない」を足したプロンプト: consistent。
  - Opus に元のプロンプト: consistent。
- 1件で列が止まるので、1クラスタが通る率 31/32 のとき、列が通る確率はクラスタ段だけで約 37% になる。この先、想起素材・用語集・台本の判定が数百回続く。

## Options

### Option A: プロンプトだけ直す(Haiku のまま)
- 費用: 変わらない。
- 短所: 止まった要約で直ったのは1件だけで、Haiku の誤判定率がどこまで下がるかは未観測。

### Option B: モデルだけ Opus にする
- 費用: 含意判定は 350〜500 回で、呼び出しの過半を占める。それが Opus の固定オーバーヘッド(1回あたり約 1.6 倍)と Opus 枠に移る。
- 短所: プロンプトが要約の形を想定していない点は残る。

### Option C: 両方
- 誤判定は最も減る見込み。費用は B と同じ。

## Decision

**Adopted**: Option C(人の判断、2026-09-28)。

- `llm_prompts.MODELS["check_entailment"]` を `claude-opus-5-5` にする。
- `ENTAILMENT_SYSTEM` に、次を足す。
  - statement は reference の複数の問題をまとめた要約でありうること。
  - reference の一部を省略すること、一般化すること、reference に書かれていない事柄に触れていないことは、矛盾ではないこと。
  - statement の主張が reference の正解・解説と両立しないときだけ contradicted とすること。
- 3値の意味と「`contradicted` と `uncertain` の両方で止める」(D-042)は変えない。

**Reason**: 切り分けで、どちらの変更でも止まった要約が consistent になった。1回の誤判定で列全体が止まるので、誤判定を減らす側に費用を払う。

## Consequences / results

- ADR-015 の「含意 = Haiku」はこの ADR で置き換える。分類・要約・想起・用語の割り当ては変えない。
- モデル ID とプロンプトは各段の `inputs_digest` に入る。そのため、cluster・recall・glossary・script の各段のキャッシュが1回無効になる。
- **Opus 枠の消費が大きく増える。** ADR-015 が「Opus 枠に当たると止まる」と書いた短所が、判定の回数分だけ重くなる。T-047 の列は、週次枠の途中で止まって再開(`--resume`)を要する見込みが上がる。
- 判定の感度が落ちていないかは、手書きフィクスチャ(D-043)で見る。ただし、これが測るのは判定器のロジックで、モデルの判定能力ではない(D-044 の穴は残る)。

### What this requires of a person

- なし(定数とプロンプトの変更)。

### Reversibility

- **可逆**。定数を戻すだけで済む。ただし、戻すと各段のキャッシュが再び無効になる(枠と時間を1回分使う)。
