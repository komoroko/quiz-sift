# ADR-026: 含意判定に落ちた生成物を、その項目だけ上限つきで作り直す(ADR-022 の「不合格の扱い」を改める)

- **Status**: proposed
- **Date**: 2026-10-12
- **Decider**: human (finalized at the mandate)
- **Related requirements**: NFR-1、R-4、R-3、NFR-7

## Background / problem
ADR-022 は「含意判定の不合格は再生成しない」を採り、「含意判定の不合格も再生成する」案を「判定器が通すまで引き直す形になり、NFR-1 の守りが弱まる」として退けた(D-191)。cluster 段の要約とグロッサリの説明は、もともと1件の不合格で段ごと止まり、作り直さない。

実デッキのフル処理で cluster 段の要約の検査まで達した列は5本あり、そのうち3本が止まった。前サイクルの 7d685472…(UngroundedSummary)と ed330309…(EntailmentRejected)、今サイクルの試行2の 47a478dc…(EntailmentRejected、2026-10-12)である。前サイクルの 591e7bb9… と今サイクルの f72c0ea9…(2026-10-09)は、同じデッキで通った。recall 段の含意判定(190 問で約 400 件)と glossary 段は、実デッキでまだ一度も走っていない。1件の不合格で列全体が完走不能になり、不可逆の試行は残り1回しかない。

## Options

### Option A: 落ちた項目だけを上限つきで作り直す(cluster・glossary・recall)
- Overview: 含意判定が `consistent` でなかった生成物は書かずに捨て、その項目(クラスタの要約、用語の説明、1問の想起素材)だけを作り直す。作り直しは最初の1回と合わせて最大 `1 + MAX_REGENERATIONS`(= 3)回まで行い、超えたら従来どおり成果物を出さずに非0終了する。
- Cost: 落ちた項目ごとに、生成と判定の呼び出しが最大2組増える。
- Security: 矛盾した生成物が成果物に書かれることは従来どおり無い。代償として、判定器が見逃す誤り(偽陰性)が通る機会は1項目あたり最大3倍になる。
- Non-functional: 確率的な1件の不合格で列全体を失うことが無くなる。
- Implementation effort: 3つのモジュール。
- Pros / cons: 完走の見込みが上がる。判定器の偽陰性に対する守りは弱まる。

### Option B: 含意判定の不合格は作り直さない(ADR-022 のまま)
- Overview: 実在性の検査の作り直しだけを足す。
- Cost: なし。
- Security: 守りは今のまま。
- Non-functional: 実デッキでは cluster 段の要約だけでも、検査まで達した5本中3本が止まっている。最後の試行が完走する見込みは低い。
- Implementation effort: 小さい。
- Pros / cons: NFR-1 は字面どおり守れる。不可逆の試行の予算を使い切る見込みが高い。

## Decision
**Adopted**: Option A

**Reason**: 人の回答(2026-10-12、D-232)。NFR-1 の目的は、矛盾した生成物を学習者に届けないことにある。生成物を捨てて作り直しても成果物には何も書かれないので、目的は保てる。判定器の偽陰性が増える分は、上限を2回に抑えて引き受ける。

## Consequences / results
- NFR-1 の基準「矛盾する生成物でエラー終了する」は「矛盾した生成物は書かず、その項目だけを上限まで作り直し、超えたら成果物を出さずにエラー終了する」に改める。R-4 の「含意判定の不合格は再生成しない」も改める(D-191 の改訂)。
- cluster 段: クラスタごとに「要約 → 実在性の検査 → 含意判定」を行う。どちらかに落ちたら、そのクラスタの要約だけを作り直す。上限を超えたクラスタが出た時点で、最後に落ちた検査に応じて `UngroundedSummary` か `EntailmentRejected` で止める。
- glossary 段: 照合先のある用語ごとに判定する。`consistent` でなければ、その用語の説明だけを作り直す。全用語を判定したうえで、上限を超えた用語があれば `EntailmentRejected` で止める。
- recall 段: 含意判定を1問の検査の最後に置き、`entailment` という検査名で他の1問単位の検査と同じ上限を共有する。上限超過は D-217 と同じく、全問を回し切ってから `RegenerationExhausted` で止める。
- script 段は文を生成せず、recall の文を判定し直すだけなので作り直す対象が無い。recall で通った文が script の判定で揺れて落ちるリスクは残る。
- ログに載せるのはクラスタ ID か問題 ID か用語の通し番号と、検査名・回数だけにする(NFR-2)。

### What this requires of a person
- なし。

### Reversibility
- 可逆(コードの変更だけ)。
