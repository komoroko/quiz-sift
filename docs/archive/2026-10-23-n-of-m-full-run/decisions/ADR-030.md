# ADR-030: 台本段は含意判定を呼ばず、想起素材の段の判定で通す

- **Status**: proposed
- **Date**: 2026-10-20
- **Decider**: human (finalized at the mandate)
- **Related requirements**: NFR-1、NFR-7

## Background / problem
フル処理の試行6(列 ed3dabc5…)は、cluster と recall を通った。recall は 190/190 問、作り直し 48 回、上限を使い切った問題は 0 だった。その後、script 段が `EntailmentRejected` で止まった。トラック c008-5 の p001-q096 の識別ポイントが `contradicted` と判定された。

同じ主張を判定し直すと、次のように6回とも `consistent` だった。判定器(Sonnet 5.5)のゆれによる偽の停止である。
- script 段と同じ形で3回。
- recall 段と同じ形で3回。

台本は、想起素材の本文を並べ直すだけで文を生成しない。答えは、要素を半角空白でつなぐだけである。識別ポイントと答えの要素は、想起素材の段で、同じ reference と同じ誤答の本文で判定済みである。想起素材の成果物は、全問が `consistent` のときだけ書かれる。台本段には作り直しが無いので、判定のゆれがそのまま試行を1回使う。これは ADR-026 が残したリスクである。

## Decision
1. `generate_scripts` は判定器を受け取らない。ラベル列挙・分割・答えの要素の欠けの検査を通れば、成果物を書く。トラックが0本なら、成果物を書かずに止める。
2. script 段の途中結果(ADR-028 の script の側)をなくす。LLM を呼ばないので、再開では台本を最初から組み立て直す。段のキャッシュ鍵から、含意判定のプロンプトとモデルを外す。
3. 想起素材の段の含意判定は変えない。

## Options considered and rejected
- **要素が2つ以上の答えの連結だけを判定する**: 連結も、判定済みの要素を並べただけである。15 問ぶんの偽の停止の機会が残る(レビュー AR-I2)。
- **台本段で `consistent` でない判定を聞き直す(多数決)**: ゆれを聞き直しで隠すだけで、判定し直す理由は無いままになる。

## Consequences
- 想起素材の段の判定が矛盾を見逃した主張(偽陰性)を、台本段の2回目の判定で拾い直す機会が無くなる(NFR-1 の代償)。
- 台本段の判定と途中結果を証拠にしていた基準(T-064 A-3、T-076 A-1〜A-3、T-084 A-3)は、計画から外す。代わりは T-088 の A-1・A-2 である。
- フル処理1本あたりの script 段の呼び出しは、約 190 から 0 になる。
