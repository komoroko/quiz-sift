# ADR-027: メソッドごとのモデルの割り当てを改める(含意判定を Sonnet 5.5、用語説明を Opus 5.5 にする)

- **Status**: proposed
- **Date**: 2026-10-13
- **Decider**: human (finalized at the mandate)
- **Related requirements**: NFR-7、NFR-1、R-5

## Background / problem
前サイクルの ADR-015 は、分類・要約を Opus、想起素材・用語説明・含意判定を Haiku 4.5 にした。含意判定は ADR-019 で Opus 5.5 に上げた。フル処理の試行3(列 876150982ad5…、2026-10-13)の recall 段の区間では、ログの単価で推定したコストの約3分の2が Opus の含意判定(61 回)で、Haiku の生成(33 回)は約3分の1だった。含意判定は判定の呼び出しが最も多い(recall・script・glossary・cluster のすべてで走る)。

## Options

### Option A: 生成は Opus(recall の生成だけ Haiku)、含意判定は Sonnet 5.5
- Overview: `classify_clusters`・`summarize_cluster`・`describe_term` は `claude-opus-5-5`、`generate_recall` は `claude-haiku-4-5` のまま、`check_entailment` は `claude-sonnet-5-5`。
- Cost: Sonnet 5.5 の単価は Opus 5.5 の半分(入力 $2・出力 $10 / MTok)。用語説明は Haiku から Opus に上がる。glossary はこのサイクルのフル処理に含めない(D-234)。
- Security: 変わらない(argv はモデル ID だけが違う)。
- Non-functional: 判定器の質が Opus から Sonnet に変わる。NFR-1 の判定能力そのものは測らない(D-043/D-044 のまま)。
- Implementation effort: 定数の置き換え、単価表に Sonnet 5.5 を足す、固定オーバーヘッドの較正を Sonnet 5.5 で1回取る(合成プロンプト、可逆)。
- Pros / cons: 判定のコストが半分になる。生成の質は Opus に寄せられる。判定器が変わるので、cluster 段のキャッシュ鍵が動いて作り直しになる。

### Option B: 全部 Opus のまま判定だけを減らす
- Overview: 判定の呼び出しを束ねて回数を減らす。
- Cost: 呼び出しごとの固定オーバーヘッドは減るが、判定のトークン量は変わらない。
- Implementation effort: 判定の入出力の形を変える。各段のテストに波及する。
- Pros / cons: 人の判断で採らない。

## Decision
**Adopted**: Option A

**Reason**: 人の回答(2026-10-13、D-236)。要約などの生成は Opus、含意判定は Sonnet でよい。recall の生成は消費を抑えるため Haiku のまま。

## Consequences / results
- `llm_prompts.MODELS` を改める。モデル ID は `inputs_digest` に入る(AR-21)ので、cluster・recall・glossary・script のキャッシュ鍵がすべて動く。試行3の列は `--resume` で cluster から作り直す(試行は消費しない)。
- `pipeline/meter.PRICES` に Sonnet 5.5 を足す(キャッシュの読み出しは Opus 5.5 と同じく入力の 0.05 倍、料金ページの脚注)。足さないと列の推定コストが `unknown_model` になり、T-071 の A-1 の判定が通らない。
- `pipeline/overhead.OVERHEAD` に Sonnet 5.5 の定数を、Opus と Haiku と同じ方法(k = 1, 2, 3 の3点、最終 argv)で取って足す(NFR-7、C-019)。較正表は `docs/test/measurements/overhead-claude-sonnet-5-5.md`。較正は別のタスクにし、フル処理を待たせない(フル処理の判定は overhead の状態を読まない)。較正の既知長 `UNIT` が Sonnet 5.5 で1トークンでなければ、線形性の判定が赤になる。そのときは較正のタスクを `blocked` で止め、人に返す。
- Haiku 4.5 は recall の生成で使い続けるので、その単価と定数は残す。

### What this requires of a person
- なし(較正はループがホストで走らせる。合成プロンプトだけ)。

### Reversibility
- 可逆(定数の変更)。ただし切り替えは該当段の作り直し(枠と時間を1回分)を意味する。
