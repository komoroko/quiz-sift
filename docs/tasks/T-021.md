## Notes / design decisions

- 実測の実行主体は「人が環境を用意し、ループが実行する」(D-076)。再レビュー AR-7 で値の assert を入れた。
- **A-2 のスクリーンショットは `docs/test/measurements/ui-e2e/` に置いてコミットする**(D-080)。初版は `out/ui-e2e/` に置いており、それは T-021 自身(kind が integration でリポジトリルートを使う)でしか緑にならなかった。parallel タスクは `git worktree add` の追跡ファイルだけのチェックアウトで走るので `out/` が存在せず、DoD の `test` ステップ(`pytest -q` で全スイート)が `test_ui_e2e_passed_and_screenshots_exist` で赤になる。T-018 が実際にこれで blocked になった(2026-09-23)。品質プロファイルは worktree を bind マウントするので gitignore 対象もサンドボックスから見えること自体は実測済みだが、見えるかどうかがそのタスクの走る木に依存する以上、判定の緑を環境に預けることになる。
- **E2E は架空のデッキに対してのみ走らせる**(D-081)。D-080 でスクリーンショットが追跡対象になるため、実教材から取り込んだデッキに対して回すと NFR-2 を画像として破る。初回の実測は架空の4問のデッキで走っていたが、T-019 / T-020 が `out/` に実データを置いた後の回し直しでは偶然に頼れない。
