## To do

`ports/process.py` に `CommandSpec` / `CommandResult` / `CommandRunner` Protocol を、`adapters/claude_process.py` に
`SubprocessRunner`(実 spawn)と `Workspace` を置く。ADR-014 の「ゲートで差し替えるのは spawn だけ」の境界の
実物側。

- 子プロセスの環境は**明示的に構築した辞書だけ**(`HOME` / `PATH` / `LANG` / `TZ`)。親環境を継承しない。
- `Workspace(home_root=None, cwd_root=None)`。`None` の既定は**本体で**解決する(`Path.home() / ".quiz-sift-claude-home"`
  と一時ディレクトリの根)。キーワード既定値にクラス呼び出しや `Path.home()` を書かない — `ClaudeCliLlm.__init__` が
  `Workspace()` を引数なしで呼ぶので、既定の解決はここで行う(設計 NFR-8 節、AR-73)。
- `new_cwd()` は毎回 `mkdtemp` でリポジトリの外に空ディレクトリを作り、呼び出しの後始末で消す。
- ロックは最小ホームのディレクトリ fd への `fcntl.flock`(D-105)。取れなければ待たずにエラー終了。
- `SubprocessRunner()` / `Workspace()` の構築は副作用を持たない。検査は `claude_process.preflight()` に集め、cli が LLM を使う段の前に呼ぶ(D-115、T-028)。
- 最小ホームの検証(preflight): `.claude/.credentials.json` の**存在だけ**を確かめる(開かない、NFR-3)。
  `settings.json` / `CLAUDE.md` / `.mcp.json`(`HOME` 直下と `.claude/` 直下)があればエラー終了。
- `claude` が `PATH` に無ければ preflight でエラー終了(R-3)。子プロセスの `PATH` は親の値をそのまま写す。
- タイムアウトは `FailureKind.TIMEOUT`(T-031 の `ports/metering.py`。D-104)で返す。
- タイムアウトは子プロセス1本ごと(既定 10 分)。プロンプトは `subprocess.run(input=...)` の stdin だけ。

scope: `src/quiz_sift/ports/process.py`, `src/quiz_sift/adapters/claude_process.py`, `tests/adapters/__init__.py`, `tests/adapters/test_claude_process.py`

## Acceptance criteria

> 機械可読な写しは `.rein/plan.yaml` のこのタスクの `acceptance:` にあり、ループが読むのはそちら。

- **A-1**: 親環境に NFR-8 が列挙した 13 個の metered 認証変数すべてに値を入れた状態で、SubprocessRunner が子プロセスへ渡す環境の変数名の集合が {HOME, PATH, LANG, TZ} と一致し(部分集合ではない)、HOME が最小ホームを指す。期待集合はテスト側に要件から写した定数として置き、実装の定数を読まない。 PATH の値は親の PATH をそのまま写す。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_child_env_is_exactly_the_allowlist`
- **A-2**: Workspace(home_root, cwd_root) を tmp_path を根にして実物のまま走らせ、new_cwd() がリポジトリの外に空ディレクトリを作り、呼び出しの後始末でそれを消す。HOME 配下のファイル一覧は new_cwd と後始末の前後で変わらない。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_workspace_makes_an_empty_cwd_outside_the_repo_and_cleans_it`
- **A-3**: 最小ホームのロックは最小ホームのディレクトリ自身の fd に対する fcntl.flock で取り、ファイルを作らない。別プロセスが保持している間の取得は待たずにエラー終了する。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_second_holder_fails_fast_without_a_lock_file`
- **A-4**: claude_process.preflight() が、最小ホームに .claude/.credentials.json が無い、または settings.json / CLAUDE.md / .mcp.json のいずれかがある場合にエラー終了する。資格情報ファイルは存在を確かめるだけで開かない。SubprocessRunner() と Workspace() の構築そのものは副作用を持たない(D-115)。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_minimal_home_is_validated_without_reading_credentials`
- **A-5**: PATH に claude が無いとき、claude_process.preflight() が非 0 のエラー終了になり、メッセージが claude の不在を名指す。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_missing_claude_binary_fails_at_startup`
- **A-6**: SubprocessRunner は子プロセス1本ごとにタイムアウト(既定 10 分)を持ち、超過で子を終わらせて FailureKind.TIMEOUT を返す。プロンプトは stdin でだけ渡り、一時ファイルを作らない。  
  判定: `pytest -q tests/adapters/test_claude_process.py::test_timeout_and_prompt_travels_only_on_stdin`

## Notes / design decisions

- 最小ホームは**人が用意する**(`HOME=~/.quiz-sift-claude-home claude /login`)。製品は作らない・コピーしない(ADR-014)。
- `claude` 自身は起動のたびに `.claude.json`・`.claude/projects/**`・`statsig/` を書く。検証が禁じるのは人が置いて
  はならない3種だけで、CLI が書くものは禁じない(D-096)。
- プロセス間ロックが要るのは、R-3 の「キャッシュを迂回した2回の実行」や人の別シェルが同じ最小ホームを同時に使いうるため(AR-64)。
