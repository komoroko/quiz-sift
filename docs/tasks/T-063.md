## Acceptance criteria
> 機械が読む写しは `.rein/plan.yaml` のこのタスクの `acceptance:`。

- **A-1**: 想起キーの各語は、その問題の問題文に G-1 の意味で実在するときだけ通る。選択肢か解説にだけある語は ungrounded になる。他クラスタ出現率とクラスタ要約の照合先は問題文・選択肢・解説のまま(D-198)。  
  判定: command — `pytest -q tests/acceptance/test_analysis.py::test_c004_recall_keys_are_grounded_in_the_stem_only`
- **A-2**: 3つの検査は grounding.presence.is_present だけを呼び、照合先は grounding/targets.py の定数からしか作られない。RECALL_SYSTEM は render_recall_system(RECALL_KEY_FIELDS) と一致し、別の fields を渡すと検査とプロンプトの両方が変わる。  
  判定: command — `pytest -q tests/recall/test_targets.py::test_prompt_and_check_share_one_definition`
- **A-3**: 識別ポイントは distractor_ids を1件以上持ち、すべてその問題の誤答選択肢である。本文の括弧は検査しない。答えは要素ごとに選択肢 ID を持ち、ID の集合が正解の集合と一致しない(不足・超過・重複・正解でない ID)と検査で落ちる。  
  判定: command — `pytest -q tests/acceptance/test_analysis.py::test_c004_answers_and_distractors_are_structured_by_option_id`
- **A-4**: 重複キーは異なるクラスタの素材の間だけで数えられ、クラスタ順で後の問題が作り直しの対象になる(D-200)。  
  判定: command — `pytest -q tests/recall/test_verify.py::test_duplicates_count_only_across_clusters`
- **A-5**: 1問単位の検査かクラスタをまたぐ重複に落ちた問題だけが上限 2 回まで再生成され、問題ごとの回数が report に記録され、再生成の呼び出しも llm_calls と provider_invocations に数えられる。含意判定の不合格と LLM 呼び出しの失敗は再生成されない。上限を超えた問題があれば全問を回し切った後にすべて列挙して成果物を出さずに非 0 終了する。  
  判定: command — `pytest -q tests/acceptance/test_analysis.py::test_c004_failed_questions_are_regenerated_up_to_twice`
- **A-6**: 含意判定の reference は正解 N 件すべてを含み、答えの要素は対象の正解を明示して判定され、識別ポイントは「誤答選択肢(この問題では正しくない記述)」の節に参照先の本文を含む。スタブ判定器が要素1件だけ、または参照先の誤答とだけ矛盾と返すと EntailmentRejected で成果物が書かれない。言い換えのフィクスチャでは誤検出 0。グロッサリの reference は変わらない。  
  判定: command — `pytest -q tests/acceptance/test_analysis.py::test_c013_contradiction_blocks_output tests/acceptance/test_analysis.py::test_c013_one_contradicting_element_blocks_output`
- **A-7**: クラスタ要約の含意判定の reference は、クラスタ内の各問題の正解をすべて含む(先頭の1件だけにしない)。  
  判定: command — `pytest -q tests/cluster/test_summary.py::test_summary_reference_lists_every_correct_option`
- **A-8**: 判定器に渡る reference の本文そのものを検査する: 答えの要素では対象の正解の本文と正解 N 件の本文、識別ポイントでは「誤答選択肢(この問題では正しくない記述)」の節と参照先の誤答の本文が入り、参照していない誤答の本文は入らない。  
  判定: command — `pytest -q tests/safety/test_entailment.py::test_reference_text_holds_the_right_sections`
