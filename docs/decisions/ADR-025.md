# ADR-025: フル処理の実行者・試行の定義・リハーサル(ADR-018 の運用を改める)

- **Status**: proposed
- **Date**: 2026-10-06
- **Decider**: human (finalized at the mandate)
- **Related requirements**: NFR-7、R-7、R-3、R-2、R-4

## Background / problem

前サイクルのフル処理(元の T-047)は、想起素材の段で止まって完走しなかった。このサイクルで完走させる。
フル処理は不可逆(教材本文が最小ホームのセッション記録に平文で残る(D-086)、レート枠を消費する)。

loose-rein 0.13 では、不可逆のタスクの長い決定的な部分を `operate` でループが走らせる。ただし operate は既定で品質ゲートの OCI(ネットワーク無し、claude・CosyVoice 無し)で走る。また、週次枠で止まって何日もかけて `--resume` する走り方を、1回の operate では保持できない。

## Options

### 実行者
- **A(採用)**: 人がホストで実行の道具(`tests/measurements/test_full_run_logs.py exec`)を走らせ、枠で止まれば同じ列を `--resume` で続ける。ループは記録の整形(`render`)と判定だけを行う(D-190)。
- B: `config.yaml` にホストのプロファイルを足し、operate で走らせる。凍結された environment に PATH と CosyVoice の場所を入れる。枠で止まると、その試行はそこで終わる。

### 試行の単位
- **A(採用)**: `--fresh-run` で始めた列1本が1回。同じ列の `--resume` は数えない。再現性の2列(cluster 段だけ)は予算の外(D-181)。最大 3 回。
- B: 起動1回を1回とする。枠で止まるたびに予算を使う。

### リハーサル
- **採用**: 次の2本を、フル処理より前に可逆のタスクとして置く(D-183)。
  - 合成デッキ(日英・複数正解を含む 10〜20 問、`tests/fixtures/decks/` にコミット)を実 CLI で recall 段まで通す。exit 0・全検査 0・含意判定の通過、再生成回数とレート枠の使用率を記録する。
  - 合成した短い台本1本(文と間を含む)を、製品の audio 段と同じ経路(合成 → 間の挿入 → mp3 → 復号 → 無音判定)で実 CosyVoice(torch 2.10)に通す(D-215)。
- 実データの小さな列は置かない。

### 実データの入手(R-2)
- **採用**: まず保存済みの生 HTML をオフラインで再抽出する(可逆)。期待件数(190 問、5択2正解 13・6択3正解 2)に届かないときだけ、人が Udemy から取り直す(不可逆、試行1回、D-180)。

## Consequences / results
- フル処理のタスクは `reversible: false`。rehearsal は合成デッキのリハーサルと TTS プローブ、attempts は max 3。
- 1試行のコストは、前サイクルの記録(n = 175)からの推定で、子プロセス 1,000〜1,500 本・壁時計 5〜8 時間・notional $150〜250(実課金ではない)。週次枠の相当部分を使う。実測ではない。
- リハーサルの呼び出し数とトークン数を 190 問に外挿し、前サイクルの列の utilization とトークン数の比から枠の使用率を推定して、フル処理の前に人に示す(D-218。utilization の差分は小数2桁に量子化されるので直接は外挿しない)。
- 記録の整形(render)も人が走らせ、ループは `out/` を読まない(D-220)。
- 受入基準は前サイクルの元の T-047 の A-1〜A-6 に戻す(途中までの記録の A-1〜A-4 は置き換える)。
- 取り直しが要る場合、そのタスクも `reversible: false`(rehearsal は再抽出、attempts は max 1)。

### What this requires of a person
- 最小ホームと資格情報、CosyVoice のチェックアウトと重みを用意すること。
- 週次枠のリセット後にフル処理を始め、枠で止まれば `--resume` で続けること。
- 生成された音声を端末へ転送して聞くこと。
- 取り直しが要る場合は、ログイン済みの Chrome をデバッグポート付きで起動し、二要素認証やボット検知に対応すること。

### Reversibility
- フル処理は不可逆: 教材本文が最小ホームのセッション記録に残り、レート枠を消費する。
- Udemy からの取り直しは不可逆: アカウントのアクセス履歴が残る。
- 再抽出・合成リハーサル・TTS プローブは可逆。
