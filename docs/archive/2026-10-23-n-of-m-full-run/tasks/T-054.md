## Acceptance criteria
> 機械が読む写しは `.rein/plan.yaml` のこのタスクの `acceptance:`。

- **A-1**: docs/test/measurements/claude-cli-flags.md が、ホストの claude --version の出力と、--help に現れるフラグのうちユーザ設定の読み込み元とツールの有効化に関わるものの名前の一覧を記録している。記録は collect_claude_cli.py の flags サブコマンドが書き、合成プロンプトだけを使う。  
  判定: command — `pytest -q tests/measurements/test_claude_cli_flags_logs.py::test_flags_record_lists_version_and_candidate_flags`
- **A-2**: 有効ツールの許可リストの候補フラグそれぞれ(空の許可リストと StructuredOutput を明示したもの)について、拒否リストを外した argv での init.tools と、--json-schema の構造化出力が返ったかが記録されている。権限の自動承認のフラグ(--allowedTools など)は候補に数えない。  
  判定: command — `pytest -q tests/measurements/test_claude_cli_flags_logs.py::test_flags_record_has_init_tools_per_allowlist_candidate`
- **A-3**: 記録の末尾の「## 結論」に、次の2行がこの形で書かれている: 「ユーザ設定の遮断: あり(<フラグ>)」または「ユーザ設定の遮断: なし」、「許可リスト: 一致あり(<フラグと値>)」または「許可リスト: 一致なし」。一致ありは、拒否リストを外した argv で init.tools が {StructuredOutput} と一致し構造化出力が返った候補があることを指す。  
  判定: command — `pytest -q tests/measurements/test_claude_cli_flags_logs.py::test_flags_record_states_the_chosen_flags`
