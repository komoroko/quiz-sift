# ADR-008: 台本が3分を超えたときは台本のみを分割する

- **Status**: accepted
- **Date**: 2026-09-22
- **Decider**: human (finalized at the mandate)
- **Related requirements**: R-6, R-3, R-7, R-10

## Background / problem

R-6 の受入基準は「上限を超えたクラスタは打ち切らず、クラスタ分割または再生成で対処し、超過した
クラスタが列挙される」と書いてあり、どちらを採るかは未定だった(AR-18 の処置で「打ち切らない」ことだけ
が決まっている)。

## Options

### Option A: 台本のみを分割(1クラスタが複数トラック)
- Non-functional: **R-3 のクラスタ数 M を動かさない**ので、退化ガードの指標も再生リストの単位も
  そのまま。R-7 の「全クラスタ分の音声」が 1:N になることを設計で明記する必要がある。
- Implementation effort: 小。

### Option B: クラスタを分割
- Non-functional: 1クラスタ = 1音声が保たれる。**ただし M が変わるので R-3 の M/N・最大クラスタ比率・
  その他比率が後から動き、退化ガードの測定対象が崩れる**。

### Option C: LLM に短く再生成させる
- Pros / cons: 構造は単純だが、固定回数で収束しないと無限ループになり、再生成のたびに課金が乗る。

## Decision

**Adopted**: Option A(台本のみを分割)

**Reason**: R-3 の測定対象を動かさないことを優先した。退化ガードは AR-2 の2巡目でようやく
意味のある形になったもので、後から M が動く設計はそれを崩す。

## Consequences / results

- ファイル名は `012a_`, `012b_` のようにパート記号を持つ。`sorted()` の結果が意図順と一致する。
- **R-7 の「全クラスタ分の音声ファイル」は 1:N になる**。設計と受入基準の解釈をここで固定する。
- **分割は `Prompt | Pause | Answer` を最小単位とし、その境界でしか割らない**(AR-8)。
  素朴に長さで割ると `Pause` を1つも含まないパートが生まれ、そのパートは R-7 の無音構造基準
  (先頭と末尾を除く位置に3秒以上の無音があり、前後に有音がある)を**必ず**落とす。
  最小単位でも3分を超える場合は分割せず、R-6 の再生成側へ倒す。
  この規則により、**聞く人が受け取る1ファイルに必ず「間」がある**という性質が保たれる。
- 超過したクラスタは列挙される。
- **What this requires of a person**: なし。
- **Reversibility**: 可逆。`script/split.py` の差し替えで済む。
