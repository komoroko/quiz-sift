## Acceptance criteria
> 機械が読む写しは `.rein/plan.yaml` のこのタスクの `acceptance:`。

- **A-1**: 選択肢が5件・6件の問題ブロックは抽出され、3件以下・7件以上のブロックは抽出の失敗として列挙される。  
  判定: command — `pytest -q tests/extract/test_udemy.py::test_five_and_six_option_blocks_are_extracted`
- **A-2**: 正解マークが N 件(N ≥ 2)ある問題は N 件の正解として抽出され、writer は answers を書く。  
  判定: command — `pytest -q tests/acceptance/test_ingest_and_decks.py::test_c002_marked_answers_become_the_answer_set`
- **A-3**: 正解マークが無い問題で受験者の選択を正解とする経路は、選択アイコンが単一選択の形(#icon-radio-* 系)の問題でだけ使われる。複数選択の形(#icon-checkbox-* 系)と判別できない形は抽出の失敗として列挙される。4択2正解でマークが無く受験者が1件だけ選んだ合成の問題は、N = 1 として素通りしない。  
  判定: command — `pytest -q tests/acceptance/test_ingest_and_decks.py::test_c002_user_selected_only_for_single_select`
- **A-4**: ゴールデンセットの道具は集合ラベル(p001-q010=A,C の形、A〜F)を受け、抽出した正解の集合との一致で判定し、N-of-M の行が3件以上あることを判定に含める。記録は docs/test/measurements/golden-set-nofm.md に書く。  
  判定: command — `pytest -q tests/measurements/test_extraction_logs.py::test_golden_check_uses_answer_sets_and_requires_three_multi_answer_rows`
- **A-5**: 保存済みの生 HTML をオフラインで再抽出する rerun サブコマンドがあり、全問数・(N, M) の組ごとの件数・抽出の失敗の理由ごとの件数・推定経路を使った件数だけを docs/test/measurements/extraction-rerun.md に書く。問題文と選択肢の本文は書かない。  
  判定: command — `pytest -q tests/measurements/test_extraction_logs.py::test_rerun_record_holds_counts_only`
- **A-6**: T-058・T-059 の記録を判定するノード(test_rerun_record_is_well_formed、test_golden_set_nofm_matches_every_answer_set、test_deck_source_record_states_counts_and_shortfall)をこのタスクが作る。対応する記録がまだコミットされていない間は skip し、記録があれば判定する。合成の記録で、それぞれの判定が欠けた記録に赤を返すことを確かめる。  
  判定: command — `pytest -q tests/measurements/test_extraction_logs.py::test_person_record_judges_go_red_on_synthetic_defects`
