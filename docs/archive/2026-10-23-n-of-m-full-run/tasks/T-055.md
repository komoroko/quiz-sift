## Acceptance criteria
> 機械が読む写しは `.rein/plan.yaml` のこのタスクの `acceptance:`。

- **A-1**: 範囲内の (N, M) 12 組すべてを1問以上含む正常系フィクスチャを取り込むと、除外件数が 0 で、各問題の問題文・選択肢 M 件・正解 N 件が欠落なく保持される。  
  判定: command — `pytest -q tests/acceptance/test_ingest_and_decks.py::test_c001_ingest_keeps_every_field_and_lists_rejections`
- **A-2**: 範囲外の (N, M)(M=3、M=7、N=0、N=M)、正解の配列が空・重複・選択肢に無い ID を含むもの、ID が重複するものは、問題ごとに理由付きで列挙され、除外件数が報告される。選択肢の件数の理由は OPTION_COUNT_UNSUPPORTED。  
  判定: command — `pytest -q tests/acceptance/test_ingest_and_decks.py::test_c001_out_of_range_and_unresolved_answers_are_listed`
- **A-3**: 正解を単一の値で持つ旧形式(キー answer)の入力は、取り込み全体が IngestFormatError で止まる。読み替えない。  
  判定: command — `pytest -q tests/acceptance/test_ingest_and_decks.py::test_c001_single_answer_input_is_refused`
- **A-4**: Question は correct_option_ids(選択肢順・重複なし・1 ≤ N < M を構築時に強制)と answer_count を持つ。N = 1 の問題の既存の挙動(採点・生成・台本)と、HTTP API の応答の形(キー名を含む)は変わらず、既存の受入テストは弱めずに緑である。  
  判定: command — `pytest -q tests/domain/test_shared_types.py::test_question_holds_answer_ids_and_rejects_out_of_range`
- **A-5**: src と tests の Python の識別子(AST の名前・属性・import する名前・引数名)に correct_option_id・OPTION_COUNT・OPTION_COUNT_NOT_4 が残らず、取り込みの入力(tests の取り込み用フィクスチャと、テストが書く取り込み用 JSON)にキー "answer" が残らない。HTTP API の応答キーの文字列 "correct_option_id" と、想起素材・台本の "answer" は対象外(API のキーの改名は T-065)。検査するテストは名前を組み立てで作り、自分自身を数えない。  
  判定: command — `pytest -q tests/domain/test_shared_types.py::test_single_answer_names_are_gone`
