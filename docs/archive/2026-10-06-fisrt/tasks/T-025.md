## Acceptance criteria

> 機械可読な写しは `.rein/plan.yaml` のこのタスクの `acceptance:` にあり、ループが読むのはそちら。

- **A-1**: 分類応答の flatten(groups[].question_ids) + unassigned が、渡した問題キーの集合と多重集合として一致しない呼び出し(欠落・重複・未知のキーの各1件)は INCOMPLETE_IDS の失敗になり、一致する応答だけが割当を返す。  
  判定: `pytest -q tests/adapters/test_llm_contract.py::test_classification_requires_exact_id_multiset`
- **A-2**: 分類スキーマが unassigned: string[] を必須に持ち、システムプロンプトが「どこにも当てはまらない問題は unassigned に入れ、すべてのキーがちょうど1回現れること」を指示する。分類のバッチサイズが 25 である。  
  判定: `pytest -q tests/adapters/test_llm_contract.py::test_schema_requires_unassigned_and_batch_is_25`
- **A-3**: llm_anthropic.py の旧パーサ(_proposals / _string / _schema)が llm_contract.py へ移り、AnthropicLlm がそれを使う。応答に欠けたキーがあっても黙って落とす旧挙動は無くなり、同じ入力で AnthropicLlm も INCOMPLETE_IDS の失敗を返す。 含意判定の判定語のパースも llm_contract に置き、未知の判定語は CONSISTENT にならない。  
  判定: `pytest -q tests/ports/test_protocols.py::test_anthropic_adapter_shares_the_id_completeness_contract`
- **A-4**: メソッドごとのモデルが classify_clusters と summarize_cluster で claude-opus-5-5、generate_recall・describe_term・check_entailment で claude-haiku-4-5 になっている(ADR-015)。  
  判定: `pytest -q tests/adapters/test_llm_contract.py::test_model_per_method_follows_adr_015`
- **A-5**: llm_prompts.py と llm_contract.py が anthropic を import しない(AST で判定)。  
  判定: `pytest -q tests/adapters/test_llm_contract.py::test_shared_modules_do_not_import_the_sdk`
