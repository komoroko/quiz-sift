> 判定すると、片方のテストを書かないだけで両方が緑になる。

- **A-1**: 各クラスタの想起キー・答え・識別ポイントが空でなく出力される。  
  判定: `pytest -q tests/recall/test_generate.py::test_three_elements_are_non_empty`
- **A-2**: 想起キーの重複判定が frozenset(terms) で行われ、要素順を入れ替えただけのキーが重複として検出される。  
  判定: `pytest -q tests/recall/test_verify.py::test_reordered_key_counts_as_duplicate`
- **A-3**: 全構成要素が他クラスタにも出現するキーの件数が 0 で、各 term の他クラスタ出現率が記録される。  
  判定: `pytest -q tests/recall/test_verify.py::test_generic_only_keys_are_rejected`
- **A-4**: 丸写し判定が全誤答選択肢に対する一致区間の和で行われ、2件を貼り合わせた識別ポイントが赤くなる。  
  判定: `pytest -q tests/recall/test_verify.py::test_two_distractors_stitched_together_goes_red`
- **A-5**: 想起キーの語句が元問題文中に実在し、実在しない語を含むキーは赤になる(混入率 0%)。  
  判定: `pytest -q tests/recall/test_presence.py::test_recall_key_terms_exist_in_source`
- **A-6**: 識別ポイントが参照する誤答選択肢が元データに実在し、存在しない選択肢を参照するものは赤になる(実在率 100%)。  
  判定: `pytest -q tests/recall/test_presence.py::test_referenced_distractors_exist`
- **A-7**: 仕込んだ矛盾を持つ想起素材フィクスチャに対し、含意判定が呼ばれて成果物を書かずに非0終了する。  
  判定: `pytest -q tests/recall/test_generate.py::test_recall_goes_through_entailment`
