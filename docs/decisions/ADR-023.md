# ADR-023: 子 CLI の堅牢化 — ユーザ設定の遮断、ツールの許可リスト、プロセスグループの終了(ADR-014・ADR-017 を改める)

- **Status**: proposed
- **Date**: 2026-10-06
- **Decider**: human (finalized at the mandate)
- **Related requirements**: NFR-8、R-3、NFR-7

## Background / problem

前サイクルの acceptance のセキュリティレビューが次の3点を指摘した。
- SEC-001: 子の CLI は最小ホームのユーザ設定を読む。起動前の中身検査だけでは防ぎきれない。
- SEC-002: ツールの制限が拒否リスト。
- SEC-004: タイムアウト時に孫が pipe を持ち続けると `communicate()` が戻らない。

## Options

### SEC-001
- **A(採用)**: ユーザ設定を読まない指定を argv に渡す(D-178)。候補は `--setting-sources`(user を含めない)。ホストの `claude --help` で存在を確かめる。手段が無ければ `/revise` で人に戻す。
- B: 中身検査を強める。最小ホームの中身を書き換えられる経路が残る。

### SEC-002
- **A(採用)**: 有効ツールの許可リスト(`--tools` 系。空のものを含む、D-194)を渡し、拒否リストを argv から外す。`init.tools` が `{StructuredOutput}` と一致することを呼び出しごとに検査する(既存)。`--help` のどのフラグでも一致しなければ拒否リストのまま受容し、記録する(D-179)。
- B: 拒否リストを維持し、許可リストを足す。二重実装になり、どちらが効いたかが分からない。

### SEC-004
- **A(採用)**: `start_new_session=True` で起動し、タイムアウトで `killpg(SIGKILL)`、5 秒待って pipe が閉じなければ自分で pipe を閉じて `TIMEOUT` を返す(D-186)。
- B: SIGTERM → 猶予 → SIGKILL。CLI に後始末の余地を残すが、10 秒の予算を分け合う。

## Decision
**Adopted**: 3つとも A

**Reason**: 人の回答(D-178、D-179、D-193、D-194)。SEC-004 の猶予は loop が決めた(D-186)。

実測の方法(D-193):
- 中身検査を通さず実 CLI を直接起動する。最小ホームの `.claude/settings.json` をその場で一時的に書き換え、読まれると呼び出しが失敗する番兵の env(到達できない `ANTHROPIC_BASE_URL`)を置く(D-213。資格情報を写すと refresh token が回転しうるので、使い捨ての HOME は使わない)。
- 製品の `build_argv` が返す最終 argv で、指定を外すと番兵のアドレスへの接続の失敗で落ち(陰性対照、stderr の分類で確かめる)、指定ありでは成功することを確かめる。記録の argv と `build_argv` の一致はテストで機械判定する。
- 後始末は、元のバイト列の sha256 の一致で確かめる(home-probe と同じ方式)。
- 拒否リストを外すので `--settings` は argv に残らず、「フラグで渡す設定が効いたまま」は確かめない(D-212)。

## Consequences / results
- argv が変わるので、次のものを新しい argv で取り直す: 契約フィクスチャ(`tests/fixtures/claude_cli/`)、home-probe の記録、固定オーバーヘッドの較正(NFR-7)。順序は「フラグの実測 → argv の変更 → 較正」。
- home-probe の positive control(`--safe-mode` だけを外す)は、ユーザ設定を読まない指定の下では成り立たない可能性があり、作り直しが要る。
- 新しいセッションに抜けた孫は孤児として残りうる(要件はその終了を求めない)。
- 子が端末のプロセスグループから外れるので、親は SIGHUP/SIGTERM を受けて子のグループに killpg してから終わる(D-221)。
- 製品の経路に無い `adapters/llm_anthropic.py` を削除する(D-216)。依存 `anthropic` の削除は、品質ゲートのイメージの作り直しと凍結済み config への再ピンが要るので次サイクルに繰り越す(D-223)。

### What this requires of a person
- ホストで最小ホームとログイン状態を保ち、フラグの実測(合成プロンプトだけ)を `rein build` の中で走らせること。実測の間、最小ホームの設定が一時的に書き換わる。

### Reversibility
- 可逆。合成プロンプトだけを使い、教材を使わない(前サイクルの D-108 と同じ扱い)。argv の変更はコミットを戻せば元に戻る。
