# ADR-004: TTS はローカル OSS の CosyVoice

- **Status**: accepted
- **Date**: 2026-09-22
- **Decider**: human (finalized at the mandate)
- **Related requirements**: R-7, R-11, NFR-7

## Background / problem

D-022 が「『間』を機械可読マーカーで表現し、TTS が無音として解釈できること」を要求している。
また D-014 が日本語・英語の両方を扱うと決めており、**日本語の教材本文には英語のサービス名が
必ず混在する**(R-11 の受入基準)。1文の中で言語が切り替わる。

多言語 TTS の多くは「言語ごとの単一言語モデル + ルータ」であり、文中で切り替わると破綻する。

## Options

### Option A: クラウド TTS(Google / Azure / Polly)
- Cost: 文字単価の課金。90分の音声で相応の額。
- Security: 資格情報が1つ増える(NFR-3 の対象が増える)。
- Non-functional: SSML の `break` に対応しており、「間」を宣言で表現できる。
- Pros / cons: **課金が不可逆点になり、承認ゲートが1つ増える**。

### Option B: CosyVoice(ローカル OSS)
- Overview: Apache-2.0。zh/en/ja/ko で 16.7 万時間の学習。**文内コードスイッチが流暢**。
- Cost: ゼロ(ローカル推論)。
- Security: 資格情報が増えない。
- Non-functional: SSML 非対応。「間」は自前で PCM 無音を挿入する。低遅延。
- Implementation effort: モデル重みの用意が要る。

### Option C: Sarashina2.2-TTS(ローカル OSS)
- Overview: 日本語ファースト、0.8B、2026-06 公開。文内コードスイッチを公式に明示。
- Non-functional: 日本語の自然さは CosyVoice を上回る可能性が高い。
- Pros / cons: **非商用ライセンス**。個人の資格学習は範囲内だが、将来公開するなら問い合わせが要る。

### Option D: Kokoro-82M
- Pros / cons: Apache-2.0 で最も軽いが、**文中コードスイッチを謳っていない**。

## Decision

**Adopted**: Option B(CosyVoice)

**Reason**: 文中コードスイッチを正面から扱い、かつライセンスに制約が無い。
IndexTTS-2 や Fish Speech の売り(感情忠実度・ゼロショットクローン)はこの用途では使わない。

## Consequences / results

- **「間」は TTS に頼らず自前で PCM 無音を生成して結合する**。これは不利ではなく、
  無音の長さと位置が生成側で決定的になり、R-7 の無音構造判定が確実に通る。
  SSML break を「TTS が解釈してくれること」に賭けなくてよい。
- **TTS の課金が無いので、R-7 は不可逆点を持たない**。クラウド TTS を選んでいれば承認ゲートが
  1つ増えていた。NFR-7 のコスト項目からも TTS が消える。
- 日英混在テキストは**分割せずそのまま渡す**。モデルが文内で切り替える。
- ボイス ID と言語の対応表 `VOICE_TABLE` はコード内定数にする(プロバイダ API を引くと NFR-6 で
  テストできない)。
- **CosyVoice はサンドボックスイメージに入れない**(ADR-012)。実測で `pip download cosyvoice` は
  ビルドに失敗し(git clone + サブモジュール前提)、torch の CPU wheel だけで 196 MB(圧縮時)。
  `uv sync --frozen` では表現できず、入れてもイメージが数 GB 級になる。
  結果として **R-7 の「生成した mp3 に無音区間がある」は `artifact` 判定**になる。
- **What this requires of a person**: CosyVoice をホストに導入し、モデル重みを用意すること
  (git clone + サブモジュール + torch)。日本語 / 英語それぞれのボイスの選択。
- **Reversibility**: 可逆。`ports/tts.py` 越しなので `adapters/tts_*.py` の差し替えで済む。
  ただし**生成済み音声の作り直しが要る**(ローカルなので再生成コストは計算時間のみ)。
