## Acceptance criteria

> 機械可読な写しは `.rein/plan.yaml` のこのタスクの `acceptance:` にあり、ループが読むのはそちら。
> **受入基準1本につきテストのノード ID を1つ割り当ててある**(タスクレビュー AR-1)。1つのファイルで複数基準を
> 判定すると、片方のテストを書かないだけで両方が緑になる。

- **A-1**: Pause セグメントが 3.3 秒の無音 PCM として挿入され、mp3 エンコード後も 3.0 秒以上残る。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_inserted_pause_survives_mp3_encoding`
- **A-2**: detect_structure が区間列を返し、判定は「3.0 秒以上の Silent Run があり、その前後いずれにも Voiced Run がある」。末尾に無音を足すだけの実装が赤くなり、先頭/末尾に短い無音を含む音声は緑になる。  
  判定: `pytest -q tests/audio/test_silence.py::test_trailing_padding_goes_red_and_leading_silence_stays_green`
- **A-3**: ゼロ埋め連番のファイル名リストを sorted() した結果が意図順と一致し、m3u が出力される。  
  判定: `pytest -q tests/audio/test_naming.py::test_sorted_filenames_match_intended_order`
- **A-4**: AudioMeta の language と VOICE_TABLE[voice_id].language が一致する。  
  判定: `pytest -q tests/audio/test_voice_table.py::test_recorded_language_matches_voice`
- **A-5**: SynthesisReport が失敗クラスタを列挙し、部分成功時にプロセスが非0終了する。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_partial_failure_exits_nonzero`
- **A-6**: クラスタごと・合計の再生時間が記録される。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_durations_are_recorded`
- **A-7**: 日本語本文に英語のサービス名が混在するテキストを分割せずそのまま TTS ポートへ渡し、例外を投げない。  
  判定: `pytest -q tests/audio/test_synthesize.py::test_mixed_language_text_is_passed_through`
