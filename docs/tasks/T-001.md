  判定: `pytest -q tests/decks/test_manifest.py::test_manifest_rejects_unknown_language`
- **A-3**: resolve_studied(個別, デッキ既定) が 個別 > デッキ既定 > unknown の順で解決し、unknown から studied/unseen へ変換する関数が存在しない。  
  判定: `pytest -q tests/domain/test_studied.py::test_studied_resolution_order`

  判定: `pytest -q tests/domain/test_shared_types.py::test_shared_types_expose_downstream_fields`
