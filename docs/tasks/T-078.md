## To do
- `tests/measurements/test_full_run_logs.py` の `render_records` は、フル処理の列で**最後に** exit 0 で終わった cluster の実行の割当とクラスタ段のサマリを使う(今は最初の成功を使う。敵対的レビュー AR-13)。
- `render_repro_log` は、classify_clusters の `llm_calls` を、終了行の `llm_calls` から「他メソッドの子のうち TRUNCATED で出し直されたものでない子の数」を引いて出す(今は他メソッドの子プロセス数をそのまま引くので、出し直しがあると classify が 0 になる。AR-24)。出し直しは標準エラーの子プロセスの記録(`failure_kind`)から数える。終了行にはメソッド別の呼び出し数が無い(`calls_by_model` はモデル別で、classify と summarize はどちらも Opus)。
- `check_reproducibility` の「他メソッドの llm_calls が子プロセス数と同じ」の比較を、出し直しを除いた数で行う(AR-26)。classify の分割呼び出しで出し直しが起きた列は、子プロセス数が ⌈N/25⌉ でなくなるので赤のままにする(再現性の列は予算の外なので取り直す)。
