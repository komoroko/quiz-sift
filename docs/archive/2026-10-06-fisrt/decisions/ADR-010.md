# ADR-010: 語句の実在性判定は形態素解析(fugashi + unidic)

- **Status**: accepted
- **Date**: 2026-09-22
- **Decider**: human (finalized at the mandate)
- **Related requirements**: R-3, R-4, R-5

## Background / problem

R-3 は「要約に現れる主要な語句が問題文中に実在する」、R-4 は「想起キーの語句が元問題文中に実在する」
「全要素が他クラスタにも出現するキーが0件」を要求する(AR-14 / AR-21 の処置)。
日本語は分かち書きされないので、語句の切り出し方法が判定の質を決める。

## Options

### Option A: 形態素解析(fugashi + unidic)
- Cost: 辞書が数百 MB。ADR-001 によりイメージに焼く。
- Non-functional: 名詞句を正しく切り出せるので、判定が意味のあるものになる。
- Implementation effort: 小(ライブラリを呼ぶだけ)。

### Option B: 文字 n-gram の部分一致
- Cost: ゼロ。
- Non-functional: **日本語では過剰に緩い**。「の」「する」のような断片が常に一致し、
  **AR-14 が塞いだ「汎用語を想起キーにする」穴が再び開く**。

### Option C: ヒューリスティックな名詞抽出
- Overview: 大文字略語(S3, IAM)・カタカナ列・漢字連続を名詞候補として取る。
- Non-functional: 依存ゼロ。AWS 試験という領域にはよく合う(サービス名がほぼこの形)。
  一般の日本語文には弱い。

## Decision

**Adopted**: Option A(fugashi + unidic)。Option C のヒューリスティックは、
大文字略語とカタカナ列の拾い漏れを補う形で併用する。

**Reason**: AR-14 が塞いだ穴を、判定方法の緩さで開け直さないこと。

## Consequences / results

- `grounding/` に判定を集約し、R-3 / R-4 / R-5 が共有する(重複実装を作らない)。
- **サンドボックスイメージが数百 MB 増える**。ADR-001 の帰結として mandate 承認前にイメージを焼き直す。
- 英語教材では形態素解析を使わず、単語境界による分割で足りる。言語で分岐する。
- **What this requires of a person**: なし。
- **Reversibility**: 可逆だが、**イメージ再ピンを伴う**ので承認後は `/revise` 案件。
